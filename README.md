# thermoking.com.ua — редизайн

Статичний прототип нової головної сторінки «Термо Кінг Україна».

- `index.html` — сторінка
- `assets/css/styles.css` — стилі (дизайн-токени на початку файлу)
- `assets/js/main.js` — меню, форми, схема мережі станцій, анімації появи
- `assets/img/hero-frost.jpg` — головне фото (тимчасова текстура, див. DESIGN.md §6)
- `DESIGN.md` — концепція, структура блоків, рекомендації та чекліст перед запуском

Запуск: відкрийте `index.html` у браузері або `python3 -m http.server` у корені репозиторію.
